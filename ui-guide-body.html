COLOR

색

인쇄된 종이를 책상에 올려둔 상태를 화면으로 옮긴 배색입니다. 바탕(desk) 위에 지면(page)이 떠 있고, 글자는 초록기가 도는 먹색을 씁니다. 강조는 짙은 소나무색 하나, 상품번호 같은 부수 정보에만 놋쇠색을 씁니다.

라이트

--page#FAFAF6지면. 200° 방향으로 page-2 까지 그라데이션
--page-2#F2F2EB지면 아래쪽
--ink#16211C제목·본문 강조

다크

--desk#0D100F바탕
--page#1A1E1C지면
--ink#E4E8E2제목
--ink-2#A3AEA7본문

--brass#D2A44B상품번호
테마는 세 가지 상태로 다룹니다. 사용자가 라이트/다크를 명시하면 data-theme 가 붙고, 기본값인 “시스템 설정”일 때는 아무것도 붙지 않아 prefers-color-scheme 만으로 갈립니다. 그래서 색은 반드시 :root 에 전체를 정의하고, 미디어쿼리와 [data-theme] 에서는 토큰만 다시 씁니다. 어떤 색도 미디어쿼리 안에서만 정의하지 않습니다.

고정색

표지·맺음말은 테마와 무관하게 같은 인쇄물로 보여야 해서 토큰을 쓰지 않고 값을 직접 박았습니다. 표지 #0E5C4F → #093F36 → #062B25, 맺음말 #0B3A33 → #062B25, 금박 글자 #E6D6AE·#D9BE7E, 네이버 초록 #03C75A, 사진 카드 바탕 #FFFFFF.

바뀐 점. 초기 시안 대비 --accent-soft 가 #DCE7E2 → #E7EEEA 로 한 단계 옅어졌습니다. 그보다 체감이 큰 변화는 사진이 들어가면서 생겼습니다 — 사진 칸은 자리표시일 때 연한 민트(--accent-soft)지만, 사진이 채워지면 흰색 카드(#FFFFFF)가 됩니다. 상품 페이지 대부분이 채워지면서 전체 인상이 밝고 희게 바뀌었습니다. 색을 바꾼 게 아니라 면적이 바뀐 것입니다.

손대면 안 되는 것

  • Cloudflare 프록시(주황 구름)를 켜면 GitHub 이 인증서를 갱신하지 못해 90일 뒤 HTTPS 경고가 뜹니다. 꼭 켜야 하면 SSL/TLS 를 Full (strict) 로 먼저 바꾸세요.
  • 저장소 루트의 CNAME 파일 — 도메인 연결을 붙잡고 있습니다.
  • Artifact 는 외부 이미지를 불러오지 못합니다. 사진·로고를 파일 링크로 바꾸면 그쪽에서 깨집니다.
